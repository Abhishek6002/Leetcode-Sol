# LeetCode Solutions

A personal collection of LeetCode problem solutions, organized for study, practice, and reference. This repository contains implementations across one or more programming languages and aims to demonstrate clear, idiomatic solutions with explanations where helpful.

## Contents

- `/{language}/` — Solutions grouped by programming language (for example `python/`, `cpp/`, `java/`).
- `/{language}/{problem_number}_{problem_name}.{ext}` — File naming follows the pattern of `<problem-number>_<problem-name>` to make problems easy to find (e.g. `0001_two_sum.py`).
- `README.md` — This file.

## How to use

1. Browse the repository by language directory to find solutions in the language you prefer.
2. Each solution file typically contains a function or class implementing the approach; some files include a short explanation or complexity analysis at the top.
3. To run a solution locally:
   - Python: `python3 path/to/file.py`
   - C++: `g++ -std=c++17 path/to/file.cpp -o solution && ./solution`
   - Java: `javac PathToFile.java && java PathToFile`

Adjust commands for your environment and for files that expect input from standard input or include test scaffolding.

## Style and conventions

- Filenames use the LeetCode problem number and a short snake_case name: `0123_example_problem.ext`.
- Solutions aim to be readable and well-commented. When applicable, a brief description and time/space complexity are included at the top of the file.
